# CoreClip

`Generate professional Ads using AI`

## Frontend | Client

- React.js
- Tailwindcss

For setup guide, checkout [Frontend Notes](./client/README.md)

## Backend | Server

- Node.js
- Express.js
- mongoose
- cloudinary

For setup guide, checkout [Backend Notes](./server/README.md)

## How to setup locally?

- Prepare Client

```cmd
cd client
npm install
// create .env file and copy .env.example file content into .env file
cd ..
```

- Prepare Server

```cmd
cd server
npm install
// create .env file and copy .env.example file content into .env file
cd ..
```

- Root Directory

```cmd
npm install
npm run dev
// copy & paste the generated url (client) into browser to access CoreClip web app locally!
```
